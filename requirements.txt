# 标准 Web Push（VAPID + RFC 8291 内容加密）。用于 iOS/iPadOS 16.4+

pywebpush>=2.5.0,<3
# 灾备包使用 Fernet 加密后才上传私有对象存储；显式声明，避免只依赖 Web Push 的间接依赖。
